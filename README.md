# STASH.AF - Minimalist Web Diary & Link Vault

  <img src="public/logo.jpg" alt="STASH.AF Logo" width="150" height="150" />

<br />

**STASH.AF** is a premium, minimalist web application built to help you stash your favorite web links, tools, and inspirations. It features a fast, smooth UI with layered 3D aesthetics, gradients, and micro-animations to make saving and organizing links an enjoyable experience.

## ✨ Features

- **Premium UI/UX**: Designed with a layered 3D aesthetic, smooth micro-animations, and subtle gradients.
- **Categorization**: Organize your links by sources (Web, Reddit, Twitter, Tools, etc.) and categories.
- **Local Storage**: All your links are saved securely in your browser's local storage. No accounts required.
- **Import / Export**: Easily backup your vault to a JSON file and restore it at any time or on any device.
- **Favorites**: Star your top links to quickly access them from the "Starred" tab.
- **Search & Filter**: Instantly search through titles, descriptions, and tags.

## 🚀 Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Hosting**: GitHub Pages

## 🛠️ Local Development

To run this project locally and enhance the UI:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Doipayan1369/stash-web-link-vault.git
   cd stash-web-link-vault
   ```

2. **Install dependencies**
   Make sure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.
